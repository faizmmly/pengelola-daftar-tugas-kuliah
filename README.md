# Pengelola Daftar Tugas Kuliah

Aplikasi web untuk mengelola tugas kuliah (tambah, edit, hapus, ubah status, filter). Dibuat dengan TypeScript dan Vite.

## Menjalankan
1. `npm install`
2. Salin `.env.example` menjadi `.env`, lalu isi nilainya
3. `npm run dev` untuk development
4. `npm run build` untuk build produksi (hasil di folder `dist/`)

## Environment Variables
| Variabel | Fungsi |
|---|---|
| VITE_APP_NAME | Nama aplikasi |
| VITE_APP_VERSION | Versi aplikasi |

Hanya data non-rahasia yang boleh dimasukkan ke variabel `VITE_*`.

## Teknologi
Git, GitHub, npm, Vite, TypeScript.
