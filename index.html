Penjelasan Teknologi yang Digunakan

      Git dan GitHub

      Git mencatat riwayat perubahan kode melalui commit. Branch dipakai untuk mengerjakan fitur secara terpisah dari kode utama, lalu digabung kembali dengan merge atau Pull Request. Jika dua branch mengubah baris yang sama, terjadi merge conflict yang harus diselesaikan manual. GitHub menyimpan repository secara online, sedangkan push mengirim commit ke GitHub dan pull mengambil pembaruan dari GitHub. File .gitignore mencegah file tertentu (seperti node_modules dan .env) ikut terunggah.

      npm

      npm adalah pengelola paket Node.js. File package.json menyimpan daftar dependencies (dibutuhkan saat aplikasi berjalan) dan devDependencies (hanya untuk pengembangan, seperti TypeScript dan Vite). Semantic versioning berformat MAJOR.MINOR.PATCH; misalnya ^5.4.0 mengizinkan pembaruan minor dan patch, tetapi tidak major. Perintah dijalankan lewat npm scripts: npm run dev, npm run build, dan npm run preview.

      TypeScript

      TypeScript adalah JavaScript dengan sistem tipe statis, sehingga kesalahan tipe terdeteksi sebelum aplikasi dijalankan. Aplikasi ini memakai tipe primitif (string, number, boolean), array, interface (Task), type alias dan union type (Status, FilterStatus), serta generics (Store<T>, filterBy<T>).

      Compiler, Transpiler, dan Bundler

      Compiler menerjemahkan kode ke bentuk lain sambil memeriksa kesalahan; TypeScript memeriksa tipe pada tahap ini. Transpiler mengubah kode ke bahasa tingkat sama, yaitu TypeScript menjadi JavaScript yang bisa dibaca browser. Bundler menggabungkan banyak file modul (main.ts, store.ts, CSS, dan lainnya) menjadi sedikit file yang kecil dan teroptimasi untuk produksi. Pada proyek ini, Vite berperan sebagai dev server dengan hot reload sekaligus bundler saat npm run build.

      Vite

      Vite adalah build tool modern. Saat pengembangan, Vite menyajikan file langsung sehingga sangat cepat. Saat npm run build, hasilnya dikemas ke folder dist/ yang siap diunggah ke website.

      Environment Variables

      Konfigurasi disimpan di file .env (tidak diunggah ke GitHub), sedangkan .env.example menjadi template yang aman dibagikan. Variabel berawalan VITE_ ikut tertanam ke hasil build dan bisa dilihat siapa pun, sehingga hanya dipakai untuk data non-rahasia seperti nama dan versi aplikasi. Password dan API key rahasia tidak boleh disimpan di sini.
